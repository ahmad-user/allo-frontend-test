# SpaceX Rocket Fleet

A simple web app to explore SpaceX rockets using the Launch Library 2 API.

## Features

- View the SpaceX rocket list.
- Search rockets by name or description.
- Filter rockets by country.
- Add your own rocket.
- View rocket details.
- Use the app on desktop, tablet, or mobile.

## Built With

- Vue 3
- TypeScript
- Vuetify 3
- Vite
- [Launch Library 2 API](https://thespacedevs.com/llapi)

## Getting Started

Make sure Node.js and npm are installed.

1. Install the dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open the local URL shown in your terminal.
